# Loan Approval Predictor

A Machine Learning project that predicts whether a loan application will be approved or rejected using Support Vector Machine (SVM).

## Project Overview

This project uses a machine learning model to predict loan approval based on applicant information.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Support Vector Machine (SVM)

## Model

- Algorithm: Support Vector Machine (SVM)
- Kernel: RBF
- Feature Scaling: StandardScaler

## Features

- User-friendly Streamlit web application
- Loan approval prediction
- Machine learning model training
- Model accuracy evaluation

## How to Run

1. Install the required libraries:

```bash
pip install pandas numpy scikit-learn streamlit
```

2. Run the application:

```bash
streamlit run streamlit_app.py
```

## Project Files

- `streamlit_app.py` — Streamlit application
- `svm.ipynb` — Machine learning model notebook
- `loan_approval.csv` — Dataset
